# 声剪 VoxCarve

HarmonyOS 7 · API 26 · 原生 Stage 工程。创建本地项目后，可在剪辑台导入单声道或双声道 16 位 PCM WAV，拖选波形或输入时间码，试听原音和剪后结果，导出 WAV。
