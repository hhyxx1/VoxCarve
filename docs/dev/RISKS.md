# 风险与验证路径

- Picker 临时访问权限会失效。按导入事务复制到应用沙箱，确认完整再发布项目记录。后续测试退出、重启、取消及空间不足。
- 音视频轨道可能起始时间不同，PTS 可能有间隙或重排序。保留轨道起点与时基，用 PCM 帧数做音频渲染基准。带视频的导出须验证关键帧、重编码及音画同步。
- 长音轨处理使用分块解码、磁盘缓存与分层峰值。导出在临时路径完成和校验后再提交，取消与错误清除临时产物。
- Core Speech SDK 的公开结果结构没有时码。设备识别服务可选，人工绑定句段时间并复核后才能影响音频。
- MP3 和 MP4 设备支持程度需逐个验证编码配置、EOS、封装结果和外部播放。基础 WAV 路径可独立交付。
- 默认本地处理。在线供应商的数据去向、费用、保留时间和权限未核实，产品流程以人工编辑及可用的离线识别为基础。
