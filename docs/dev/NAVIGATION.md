# 声剪 · 导航

手机一级导航为项目、剪辑台、设置。宽屏沿用同样入口，以侧栏呈现。一级状态在 Navigation 宿主内切换，二级使用 NavPathStack 和 NavDestination。系统返回对普通二级页面弹栈，新建页对未保存名称显示确认。

| 路径 | 入口 | 当前状态 |
| --- | --- | --- |
| /projects | 启动、项目导航 | 真实 RDB 列表、加载、空和错误状态，可新建项目 |
| /import | 项目页新建 | 创建本地项目，媒体入口待阶段 03 |
| /timeline | 剪辑台导航、点击项目 | 当前项目标题和真实空波形状态，提供后续页面入口 |
| /transcript | 剪辑台 | 独立文字稿组件，当前空态 |
| /silence | 剪辑台 | 停顿复核路由，当前无可处理音轨 |
| /captions | 剪辑台 | 字幕路由，当前无可处理音轨 |
| /preview | 剪辑台 | 剪后试听路由，当前无可处理音轨 |
| /export | 剪辑台 | 导出路由，当前无可处理音轨 |
| /history | 剪辑台 | 历史路由，编辑历史 UI 待接入 |
| /settings | 设置导航 | 会话外观选择、离线能力说明和探测入口 |

设置 → SDK 26 探测保留阶段 01 的开发验证面板。它位于独立诊断路由，业务页仍为十个。

阶段 03 的 WAV 选择、波形、区间编辑、试听与导出已接入剪辑台。专用业务子页在后续阶段联动。
