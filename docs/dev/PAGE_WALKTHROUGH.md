# 阶段 04 · 页面走查

HarmonyOS API 26，原生 ArkUI。阶段 03 的单轨 PCM16 WAV 项目升级至 RDB v3，已有素材及编辑图继续读取。新增文字记录与外观偏好分别保存在 project_text 与 app_settings。

| 页面 | 导航与业务 | 状态与验收 |
| --- | --- | --- |
| projects | 启动或主导航「项目」。读取本地 RDB，按项目名称搜索。新建项目保存后进入导入。 | 空、无搜索结果、读取错误与重试。F13 |
| import | 新建后自动进入，已有项目从剪辑台打开。系统 Picker 授权，校验、复制真实 WAV，并生成峰值。 | 取消选择回到空态，损坏文件提示重试。压缩音频、视频和录音显示暂不可用。F01/F02/F14 |
| transcript | 剪辑台 → 文字稿。保存或编辑人工句段、说话人、源音起止。未填时间为待校准。已校准句段可选中剪辑台实际波形区间。 | 空、读取错误、非法区间、未保存退出确认。音频剪切由剪辑台提交。F03–F05 |
| timeline | 主导航「剪辑台」或点击项目。基于源 PCM 波形拖选，支持毫秒输入、保留、删除、撤销重做、原音/选区/剪后试听。 | 无项目、无素材、处理错误和空输出。F05/F06/F09 |
| silence | 剪辑台 → 停顿复核。20 ms 窗、逐声道 RMS，固定 −45 dBFS，最短停顿可调整。点击候选定位源区间，可试听再手工决定。 | 无素材、无候选、输入非法和分析失败。F07 |
| captions | 剪辑台 → 字幕。手动编辑或由已校准句段映射剪后区间，保存至项目。可导出按时间排序的 SRT。 | 无素材、无字幕、被剪除句段、重叠/超界/过短拒绝导出、取消保存。F08 |
| preview | 剪辑台 → 剪后试听。用当前编辑图渲染 WAV 临时文件并交给 AVPlayer。 | 无素材、空输出、处理失败、播放完成。视频预览仍待接入。F09 |
| export | 剪辑台 → 导出。展示实际剪后时长及保留采样率和声道的 PCM16 WAV，可改文件名，系统面板选择保存位置。 | 无素材、空输出、非法文件名、取消保存或写入失败。MP3/MP4 仍待设备验证。F10–F12 |
| history | 剪辑台 → 历史与版本。显示持久化决定、源区间和当前游标。恢复任一版本后重载剪辑台。 | 空历史、读取/保存失败。源文件以只读方式打开。F13 |
| settings | 主导航「设置」。持久化浅色、深色或跟随系统；可进入 SDK 26 探测。 | 设置写入失败提示；离线能力探测与项目媒体处理各自运行。F15 |

共享组件包括 XuzuoAppBar、NavigationShell、ActionButton、TextFieldRow、DataRow、SegmentedControl、状态面板、进度与确认对话框。AudioWorkspace 复用项目音频工作区，ProjectToolPage 承载独立二级工具路由。二级返回剪辑台；外部 URI 深链待定义。

## 规格差异与后续

停顿候选先逐段回剪辑台试听，批量处理及前后保留量待后续。字幕保存的是显式确认的剪后时间，修改剪辑后需复核。WebVTT、MP3、MP4、视频导入、录音、真实 ASR、长音频专项和运行中取消留在后续阶段。剪辑台缩放、吸附、拆分及合并也尚未验收。上述差异以本报告作为设计资料待修建议。
